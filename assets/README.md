# Profile artwork

`banner.svg` is a self-contained animated vector: outlined Space Grotesk lettering
and a mathematically drawn trefoil. It loads no scripts, external fonts or images.
Its animations become static when the visitor prefers reduced motion.

To rebuild it, install `fonttools` and run `python scripts/build-banner.py`.

Space Grotesk is by Florian Karsten and distributed under the SIL Open Font
License. The font and its license are in `fonts/`.
Source: https://github.com/google/fonts/tree/main/ofl/spacegrotesk

Technology icons in the profile are served by https://skillicons.dev.
The contribution animation is generated daily by https://github.com/Platane/snk.
